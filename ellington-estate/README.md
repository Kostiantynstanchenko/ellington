# Ellington Estate — ellingtonestate.com

Multilingual (EN · ES · DE · NL · SV) new-build property site for **Cloudflare Pages**. Pure static HTML generated by `build.mjs` (no dependencies), plus one Pages Function for enquiries.

## Structure
```
src/data/projects.mjs   ← developments (prices, types, features, coordinates, 5-language summaries)
src/data/i18n.mjs       ← all UI text per language + SITE contacts (email/phone/WhatsApp — REPLACE the placeholders)
src/blog/articles.mjs   ← journal articles (5 languages each)
src/assets/             ← styles.css, app.js
public/                 ← copied as-is (favicon, og.jpg, img/)
public/img/projects/<slug>/  ← project photos (01.jpg, 02.jpg …) — picked up automatically
functions/api/lead.js   ← POST /api/lead (forms → Telegram and/or KV)
scripts/fetch-images.mjs← pulls imagery from developers' official pages
```

## URLs (same structure in every language)
`/properties/` (full search with filters, saved in the URL) → `/properties/costa-blanca/` → `/properties/costa-blanca/finestrat/` → `/properties/costa-blanca/finestrat/marques-golf-resort/`
Type pages: `/properties/villas/`. Languages: `/es/viviendas/…`, `/de/immobilien/…`, `/nl/woningen/…`, `/sv/fastigheter/…`. Journal: `/blog/`, `/es/blog/`, `/sv/blogg/`.
Every page has canonical + hreflang, JSON-LD (RealEstateListing / ItemList / BlogPosting / Breadcrumbs) and is listed in `/sitemap.xml`.

## Images (developer imagery)
The site works without photos (it shows designed placeholders), but it needs them to sell. Two ways:
1. **Best:** ask each developer for their agent media pack and drop files into `public/img/projects/<slug>/`.
2. **Script:** put the developer's official project page into `imagePages` in `projects.mjs`, then `npm run fetch-images` (or `node scripts/fetch-images.mjs lakun`). Review the folder, delete logos/plans, keep the best 6–10, then `npm run build`.
Optional: `public/img/hero.jpg` replaces the illustrated hero.

## Deploy to Cloudflare Pages
1. Push this folder to a GitHub repo.
2. Cloudflare → Workers & Pages → Create → Pages → connect repo.
   Build command: `npm run build` · Output directory: `dist` · Node 18+.
3. Custom domains → add `ellingtonestate.com` and `www.ellingtonestate.com`; redirect www → apex with a Bulk Redirect rule.
4. Enquiries: Settings → Variables: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (and/or bind a KV namespace as `LEADS`). Without either, forms return an error.
5. Submit `https://ellingtonestate.com/sitemap.xml` in Google Search Console and Bing.

## Adding content
- **New development:** add an object to `projects` (copy an existing one), add photos, build.
- **New article:** append to `articles` with `slug`, `title`, `desc`, `body` for all 5 languages.
- **Before launch, confirm:** prices/availability with each developer; contacts in `SITE`; the business-model sentences in `about` (they say the service is free for buyers and paid by developers); the privacy text with a lawyer.
