# Ellington Estate — ellingtonestate.com

Multilingual (EN · ES · DE · NL · SV) new-build property site for **Cloudflare Pages**. 205 static pages generated by `build.mjs` (no build dependencies), plus one Function for enquiries.

## Palette & type — "Blanco & Indigo"
| Token | Hex | Used for |
|---|---|---|
| Blanco | `#f8f7f4` | page background |
| Salt | `#e5e2db` / `#efece6` | second background, borders |
| Indigo | `#16304a` → `#0e2033` | text, header, footer, dark sections |
| Brass | `#b08a4a` | the single accent: price, CTA, rules |
| Stone | `#717b84` | captions |

Cormorant Garamond (display) + Jost (text). Every colour is a CSS variable at the top of `src/assets/styles.css` — change the five tokens and the whole site follows.

## Structure
```
src/data/projects.mjs   ← developments (prices, types, features, coordinates, 5-language summaries)
src/data/i18n.mjs       ← UI text per language + SITE contacts (email/phone/WhatsApp — REPLACE the placeholders)
src/data/landing.mjs    ← landing-page copy, FAQ templates, the 6 homepage towns, airport coordinates
src/blog/articles.mjs   ← journal articles (5 languages each)
src/assets/             ← styles.css, app.js, leaflet.css, leaflet.js (vendored, no CDN)
public/img/projects/<slug>/  ← project photos (01.jpg, 02.jpg …) — picked up automatically
functions/api/lead.js   ← POST /api/lead (forms → Telegram and/or KV)
scripts/fetch-images.mjs← pulls imagery from developers' official pages
```

## What each page does
**Homepage** — hero, interactive map of all developments, the two coasts, six main towns, this season's selection, how buying works, warranties, journal.

**The map** (`#map-section`) uses Leaflet with the CARTO light basemap. Zoomed out it shows one marker per coast with a count; click it and the view flies in and the markers become price bubbles, which declutter themselves so neighbouring towns never overlap. Clicking a bubble opens a small card linking to the residence. The same component shows a single pin on every project and town page.

**Each project is a full landing page** — ad traffic can be pointed straight at it: full-bleed hero with the price and one primary CTA, sticky section nav, five-fact strip, the residence, "why this address", gallery with lightbox, location with map and distances, how buying works, warranties, six FAQs generated from that project's own data (and emitted as `FAQPage` structured data), a closing CTA with the form, and comparable addresses. On phones a sticky bottom bar carries the price, WhatsApp and the request button.

**SEO** — canonical + hreflang on all five languages, JSON-LD (`RealEstateListing`, `FAQPage`, `ItemList`, `BreadcrumbList`, `BlogPosting`), `/sitemap.xml`, `robots.txt`.

URLs: `/properties/` → `/properties/costa-blanca/` → `/properties/costa-blanca/finestrat/` → `/properties/costa-blanca/finestrat/marques-golf-resort/`, mirrored as `/es/viviendas/…`, `/de/immobilien/…`, `/nl/woningen/…`, `/sv/fastigheter/…`.

## Images (the one thing still missing)
The site works without photos — it draws designed placeholders — but it needs real imagery to sell. Two ways:
1. **Best:** ask each developer for their agent media pack and drop the files into `public/img/projects/<slug>/`.
2. **Script:** put the developer's official project page into `imagePages` in `projects.mjs`, then `npm run fetch-images` (or `node scripts/fetch-images.mjs lakun`). Review the folder, delete logos and floor plans, keep the best 6–10, then `npm run build`.

The first image becomes the hero, the second the portrait beside the text, the third the closing CTA background, and all of them fill the gallery. Optional: `public/img/hero.jpg` replaces the illustrated homepage hero.

## Deploy to Cloudflare Pages
1. Push this folder to a GitHub repo.
2. Cloudflare → Workers & Pages → Create → "Continue to Pages" → import the repo.
   Build command `npm run build` · Build output directory `dist` · Root directory: the folder holding this README, if it is not the repo root.
3. Custom domains → add `ellingtonestate.com`.
4. Enquiries: Settings → Variables and Secrets → `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (and/or bind a KV namespace as `LEADS`). Without either, the forms return an error.
5. Submit `https://ellingtonestate.com/sitemap.xml` in Google Search Console and Bing.

## Adding content
- **New development:** add an object to `projects` (copy an existing one), add photos, build. Its landing page, FAQs, map pin and town page are generated.
- **New article:** append to `articles` with `slug`, `title`, `desc`, `body` in all five languages.
- **Before launch, confirm:** prices and availability with each developer; the contacts in `SITE`; the business-model sentences in `about` (they state that the service is free for buyers and paid by developers); the privacy text with a lawyer.

Third-party: Leaflet 1.9.4 (BSD-2-Clause) is vendored in `src/assets/`. Map tiles come from CARTO over OpenStreetMap data, attributed in the map and named in the privacy policy; for heavy traffic, swap the tile URL in `app.js` for a MapTiler or Mapbox key.
